# Làm chủ Claude trong công việc

Trang khoá học đào tạo nhân viên và học viên dùng Claude. Một file `index.html`, mở bằng trình duyệt, không cần cài đặt.

## Thiết kế lại trang chủ Ẩm Thực An Tâm

Thư mục `antam/` chứa bản thiết kế trang chủ mới cho antamfoods.com theo bộ nhận diện **Điểm Chỉ 1.1** (logo vân tay chấm tâm, font An Tâm Tròn Bánh, đỏ #D2141E / kem #FFF6EA / mực #231716, hotline 0398 431 300). Logo, icon, nền đường vân và font lấy từ gói nhận diện trên nhánh `claude/design-plugin-customize-e9l5o1`; ảnh là ảnh thật tại xưởng. Mở `antam/index.html` bằng trình duyệt.
