# Làm chủ Claude trong công việc

Trang khoá học đào tạo nhân viên và học viên dùng Claude. Một file `index.html`, mở bằng trình duyệt, không cần cài đặt.

## Phòng marketing agent

Gõ `/marketing <việc cần làm>` trong Claude Code. Trưởng phòng (skill `.claude/skills/marketing`) lập brief rồi giao việc cho các agent trong `.claude/agents/`: `nghien-cuu` (R&D), `viet-bai`, `thiet-ke`, `bien-tap`. Kết quả nằm trong `marketing/<ngày>-<tên-việc>/`.
