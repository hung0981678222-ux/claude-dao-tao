# Làm chủ Claude trong công việc

Trang khoá học đào tạo nhân viên và học viên dùng Claude. Một file `index.html`, mở bằng trình duyệt, không cần cài đặt.

## Plugin Design cho công ty

Thư mục `plugins/design` là plugin Design đã tuỳ chỉnh cho công ty. Xem [plugins/design/README.md](plugins/design/README.md) để cài và dùng.
