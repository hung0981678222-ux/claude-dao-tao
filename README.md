# Làm chủ Claude trong công việc

Trang khoá học đào tạo nhân viên và học viên dùng Claude. Một file `index.html`, mở bằng trình duyệt, không cần cài đặt.

## Thiết kế lại trang chủ Ẩm Thực An Tâm

Thư mục `antam/` chứa bản thiết kế trang chủ mới cho [antamfoods.com](https://antamfoods.com/), giữ nhận diện thương hiệu (đỏ #C4121A, vàng #E59800, logo bông lúa). Mở `antam/index.html` bằng trình duyệt.
