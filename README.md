# Làm chủ Claude trong công việc

Trang khoá học đào tạo nhân viên và học viên dùng Claude. Một file `index.html`, mở bằng trình duyệt, không cần cài đặt.

## Agent marketing tổng thể

File `.claude/agents/marketing-tong-the.md` là một agent marketing lo trọn từ nghiên cứu, chiến lược, nội dung, quảng cáo đến đọc số liệu.

- **Trong Claude Code:** mở thư mục này, gõ ví dụ `Dùng agent marketing-tong-the lập lịch nội dung tháng 11 cho Doner kebab`. Agent tự đọc `marketing/brand.md` nếu có, lưu kế hoạch dài vào thư mục `marketing/`.
- **Trên claude.ai:** tạo một Project, chép phần nội dung bên dưới dòng `---` thứ hai của file vào ô *Instructions* của Project, rồi tải hồ sơ thương hiệu lên làm tài liệu của Project.
