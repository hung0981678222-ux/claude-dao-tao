# 6 font mới cho An Tâm

Mỗi font dựng từ một khung chữ mã nguồn mở (SIL OFL), đổi tên riêng, và thay mọi dấu mũ (â ê ô và các chữ có dấu kèm) bằng chiếc bánh vòm có đốm nướng. Đủ tiếng Việt.

| Số | Font | Khung gốc | Tính cách |
|---|---|---|---|
| 01 | An Tam Bricolage | Bricolage Grotesque 800 | Hiện đại, có khía mực, cá tính trẻ |
| 02 | An Tam Fraunces | Fraunces 900 | Có chân mềm, ấm, sang |
| 03 | An Tam Anton | Anton | Cao hẹp, mạnh, hợp biển hiệu và bậc thang |
| 04 | An Tam Baloo | Baloo 2 800 | Tròn mập, thân thiện, đồ ăn vặt |
| 05 | An Tam Grandstander | Grandstander 900 | Vui, nghịch, như vẽ tay |
| 06 | An Tam Dela | Dela Gothic One | Rất đậm, rộng, nổi bật từ xa |

Xem so sánh: `font-moi.html`. Dựng lại: `python3 make_fonts_multi.py` (cần các file con fontsource), rồi `python3 build_font_moi.py font-moi.html`.
